## D1｜11/09 概念基础 + 环境验证

- [ ] **LLM**：按「预测下一个 token」续写的模型，我传 messages 数组进去，它逐 token 往回流。面试怎么说：它不查数据库、不保证事实，所以才需要 RAG 和边界约束。
- [ ] **Token**：模型读写的最小单位，中文大致 1–2 字一个，输入和输出都计费。面试怎么说：控成本就是少塞无关上下文 + 限制输出长度。
- [ ] **上下文窗口**：一次请求能装下的总 token 上限，system + 历史 + 回复全算在内，超了会截断或报错。面试怎么说：今天三条模板挤在同一个 system 里「串味」，本质就是上下文里塞了互相干扰的东西。
- [ ] **生成式 vs 判别式**：生成式产出新文本（聊天、写作），判别式做归类判断（情感/标签）。面试怎么说：现在判别类任务也常用生成式模型 + 结构化输出来做，所以 JSON 能不能合法解析很关键。
