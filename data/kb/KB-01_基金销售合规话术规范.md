# 基金销售合规话术规范（教学样例）

> **重要声明**：本文件为**虚构的教学样例文档**，用于本地 RAG 知识库、权限过滤与评测集演练。
> 文中机构名称、流程编号、分值、时限均为示例值，**不是任何真实机构的制度文件**，不含任何客户数据。
> 涉及监管要求的部分仅陈述通用原则，**不引用具体条款号、处罚标准**；实际业务以现行法律法规、监管规定及所在机构最新制度为准。

## 1. 适用范围

本规范适用于面向投资者开展基金产品介绍、答疑、跟进、回访的所有口头与书面沟通场景，包括：线上客服会话、电话、即时通讯、线下路演与网点接待、以及由智能问答系统生成的回复。

智能问答系统生成的回复**视同销售话术**，须遵守本规范全部条款。

## 2. 五条基本原则

| 编号 | 原则 | 说明 |
|---|---|---|
| P-01 | 不得承诺收益 | 不得以任何明示或暗示方式承诺投资本金不受损失或最低收益 |
| P-02 | 充分揭示风险 | 介绍产品时必须同步说明风险特征、可能的亏损情形 |
| P-03 | 不得误导 | 不得使用夸大、片面、易引起误解的表述，不得混淆基金与存款、理财 |
| P-04 | 适当性前置 | 未完成风险承受能力评估与产品匹配前，不得进行具体产品推介 |
| P-05 | 只依据已审核资料 | 答复内容以现行有效、经合规审核的材料为准；资料未覆盖的内容不得自行推导 |

## 3. 禁止用语清单

| 禁止表述（示例） | 问题 | 推荐替代表述 |
|---|---|---|
| 「这个产品保本、稳赚不赔」 | 违反 P-01，暗示本金安全 | 「本产品不保证本金和收益，可能出现亏损，风险等级为 R3」 |
| 「年化至少 8%，写进合同」 | 承诺收益、虚构合同内容 | 「历史业绩不代表未来表现，业绩展示口径详见产品资料」 |
| 「跟存款一样安全」 | 混淆产品性质，违反 P-03 | 「基金不同于存款，不纳入存款保险范围」 |
| 「错过今天就没额度了」 | 制造紧迫感、误导决策 | 「募集期以基金公告为准，请您自行判断并充分阅读文件」 |
| 「公司内部消息，肯定涨」 | 暗示内幕信息、违反 P-01/P-03 | 「我们无法预测市场走势，请基于公开信息决策」 |
| 「我帮您填风险测评，选高一点就能买」 | 规避适当性管理 | 「风险测评需由您本人如实填写，测评结果决定可购买的产品范围」 |
| 「亏了算我们的」 | 变相保本、越权承诺 | 「投资损失由投资者自行承担，机构不作补偿承诺」 |

## 4. 允许且推荐的表述结构

一段合规的产品介绍建议按以下顺序组织，缺项视为不完整：

1. **产品识别**：产品全称、类型、管理人（以公开资料为准）。
2. **风险等级**：如「风险等级 R3，中风险」，并说明与投资者风险等级的匹配结论。
3. **风险揭示**：明确「不保证本金和收益，可能发生亏损」。
4. **客观信息**：投资范围、费率、赎回安排、期限等，仅引用已审核材料。
5. **依据与出处**：指向具体资料名称，便于留痕与复核。
6. **决策归属**：提示投资者阅读基金合同、招募说明书并独立决策。

## 5. 典型场景标准话术

### 场景 A：客户问「这个能保证不亏吗」

> 不能。基金产品不保证本金和收益，市场波动时可能出现亏损。本产品风险等级为 R3，是否适配需要以您本人的风险测评结果为准。具体风险因素可查阅产品资料中的风险揭示章节。

### 场景 B：客户问「去年收益多少，今年还能有吗」

> 历史业绩不代表未来表现，任何对未来收益的预测都不属于合规表述。您可以在产品定期报告中查看经审计的历史业绩，业绩展示的统计区间与计算口径以报告为准。

### 场景 C：客户要求「你直接告诉我买哪个最赚」

> 我无法替您作出投资决策，也不能预测哪只产品收益最高。我们可以先确认您的风险承受能力等级与投资期限，再在匹配范围内介绍产品信息，最终由您独立决定。

### 场景 D：资料中没有答案

> 资料中未说明。该问题涉及（具体事项），建议补充查阅〔产品合同／最新公告／合规审核口径〕后再答复，我不作推测。

> **系统实现要点**：D 类场景对应「拒答 + 说明缺哪类依据」，是防止幻觉的关键约束，不得由模型自由发挥。

## 6. 留痕与复核

- 每一次产品推介须记录：会话标识、使用的话术版本、引用的资料名称、投资者风险等级、时间戳、操作人员或系统版本。
- 智能问答系统的回复须可回溯到检索命中的文档片段（doc_id + 片段位置）。
- 合规抽查发现禁止用语时，须下架对应话术版本并记录整改，不得仅修改单次输出。

## 7. 自检六问（发布/答复前逐条过）

1. 有没有出现保本、保收益、稳赚、刚兑等表述？
2. 有没有把基金类比成存款或保本理财？
3. 风险揭示是否与产品介绍同时出现？
4. 是否已完成适当性匹配？
5. 所有数字、费率、业绩是否都能指向已审核资料？
6. 资料未覆盖时，是否明确说明"资料中未说明"而非推测？
