# 投资者适当性管理操作指引（教学样例）

> **重要声明**：本文件为**虚构的教学样例文档**，用于本地 RAG 知识库、角色权限过滤与评测集演练。
> C1–C5、R1–R5 分级、时限、分值均为示例定义，**不是任何真实机构的制度**，不含客户数据。
> 实际业务以现行监管规定与所在机构最新制度为准，本文不复述具体法条。

## 1. 适当性管理三要素

适当性管理回答三个问题，缺一不可：

1. **了解客户**：通过风险测评取得投资者风险承受能力等级。
2. **了解产品**：确定产品风险等级与关键特征。
3. **匹配与执行**：把合适的产品卖给合适的投资者，并对不匹配情形作出处置与留痕。

> 顺序不可颠倒：**未完成测评与匹配，不得进行具体产品推介**（对应 `KB-01` P-04）。

## 2. 投资者风险承受能力等级（示例定义）

| 等级 | 名称 | 典型特征（示例） | 可承受波动 |
|---|---|---|---|
| C1 | 保守型 | 首要目标是本金安全，不接受本金波动 | 极低 |
| C2 | 稳健型 | 可接受小幅波动以换取略高于存款的预期 | 低 |
| C3 | 平衡型 | 可接受一定幅度波动，追求风险收益平衡 | 中 |
| C4 | 成长型 | 可接受较大波动，追求长期资本增值 | 较高 |
| C5 | 进取型 | 可承受大幅回撤，投资期限较长 | 高 |

评定维度示例：投资期限、收入与资产状况、投资经验、亏损容忍度、流动性需求。
**测评须由投资者本人如实、独立填写**，任何人员不得代填、诱导或提示答案。

## 3. 产品风险等级（示例定义）

| 等级 | 名称 | 典型产品类别（示例） |
|---|---|---|
| R1 | 低风险 | 货币市场基金、现金管理类 |
| R2 | 中低风险 | 短债、纯债类 |
| R3 | 中风险 | 二级债基、平衡混合类 |
| R4 | 中高风险 | 偏股混合、权益类 |
| R5 | 高风险 | 高仓位权益、商品、衍生品策略等 |

## 4. 匹配矩阵（示例）

| 投资者等级 | 可购买产品等级 |
|---|---|
| C1 | R1 |
| C2 | R1、R2 |
| C3 | R1、R2、R3 |
| C4 | R1、R2、R3、R4 |
| C5 | R1、R2、R3、R4、R5 |

**核心规则**：产品风险等级不得高于投资者风险承受能力等级。
系统实现时，该判断必须在**检索层之前**完成，并把可访问文档范围作为过滤条件下推；不得仅靠提示词约束。

## 5. 不匹配情形的处置

| 情形 | 处置 |
|---|---|
| 投资者主动要求购买高于其等级的产品 | 明确提示不匹配、说明风险；按机构规定执行二次确认或拒绝，不得默认放行 |
| 测评已过期 | 先重新测评，再推介；不得沿用过期结论 |
| 测评答案前后矛盾 | 触发复核，暂停自动推介 |
| 投资者拒绝提供必要信息 | 不得完成匹配，不得推介具体产品 |
| 产品风险等级上调 | 重新校验存量持有人的匹配状态，并做通知留痕 |

## 6. 关键流程节点与留痕字段

一次完整的适当性流程至少记录以下字段：

| 字段 | 说明 |
|---|---|
| `session_id` | 会话/业务流水标识（示例字段，不含真实客户标识） |
| `investor_level` | 测评得出的 C 等级 |
| `assess_time` / `expire_time` | 测评时间与有效期 |
| `product_level` | 产品 R 等级 |
| `match_result` | 匹配 / 不匹配 / 待复核 |
| `exception_type` | 例外类型（如二次确认） |
| `witness_record` | 双录/确认记录是否存在 |
| `operator_or_system` | 操作人员或系统版本 |
| `timestamp` | 操作时间 |

## 7. 双录、冷静期与回访（示例约定）

- **双录**：特定情形下对推介过程进行录音录像，记录产品风险揭示与投资者确认；触发条件以机构最新清单为准。
- **冷静期**：部分业务设置冷静期，期间投资者可无理由解除合同；具体时限以产品文件为准。
- **回访**：对特定客户或特定产品开展回访，确认投资者知悉风险、测评由本人完成。
- 上述记录**属于敏感业务数据**，仅保存在内网系统；不得作为提示词内容发送给外部模型服务。

## 8. 信息更新与有效期

- 风险测评结论设有效期（示例：12 个月），到期或投资者情况发生重大变化时须重新评估。
- 产品风险等级变更须同步更新匹配规则，旧版本文档须标记为失效并停止被检索命中。
- 知识库中的历史版本文档应保留 `version` / `effective_date` 元数据，便于审计时解释"当时依据的是哪一版"。

## 9. 常见问题速答

**问：客户等级 C2，能买 R3 吗？**
> 不能。产品风险等级高于投资者承受能力等级，属于不匹配。应提示风险并按机构规定执行二次确认或拒绝流程，不得直接推介。

**问：客户说"测评随便填就行"怎么办？**
> 测评须本人如实独立填写，不得代填或诱导。应说明测评结果直接决定可购买范围，并提示如实填写的必要性。

**问：为什么智能问答系统也要做适当性判断？**
> 系统回复视同销售话术。若不做等级过滤，可能向低风险投资者呈现高风险产品资料，构成越权展示。过滤必须在检索层强制，而非仅写在提示词里。
