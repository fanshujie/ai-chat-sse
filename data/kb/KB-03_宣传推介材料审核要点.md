# 宣传推介材料审核要点（教学样例）

> **重要声明**：本文件为**虚构的教学样例文档**，用于本地 RAG 知识库、角色权限过滤（本文件仅对 `compliance` / `manager` 可见）与评测集演练。
> 流程编号、时限、清单项均为示例值，**不是任何真实机构的制度**，不含客户数据；实际以现行监管规定与所在机构最新制度为准。

## 1. 材料范围

需纳入审核的材料类型（示例）：产品单页与折页、海报与易拉宝、公众号推文与短视频脚本、线上 banner 与落地页、路演 PPT、客服标准话术库、智能问答系统的知识条目、邮件与短信模板。

> 由系统自动生成的回复若引用了未经审核的内容，视同发布未经审核材料。

## 2. 审核流程（示例五步）

| 步骤 | 责任方 | 输出 |
|---|---|---|
| S1 制作 | 业务/市场 | 材料初稿 + 引用资料清单 |
| S2 合规初审 | 合规岗 | 审核意见（通过 / 修改 / 驳回）+ 逐项 checklist |
| S3 复核 | 复核人 | 复核结论与版本号 |
| S4 发布 | 渠道方 | 发布记录、投放范围、生效时间 |
| S5 归档 | 合规岗 | 定稿文件、审核记录、引用依据、失效时间 |

**禁止**：先发布后补审核；使用未标注版本的旧稿；把审核通过的材料擅自改动后继续使用。

## 3. 必含要素清单

- [ ] 产品全称、类型、管理人等识别信息（与公开资料一致）
- [ ] 风险揭示语句，且位置醒目、字号不小于正文主体
- [ ] 「基金过往业绩不预示未来表现」「投资有风险」类声明
- [ ] 业绩数据的统计区间、计算口径、数据来源
- [ ] 费率、赎回安排等要素的完整说明或明确指引到何处查阅
- [ ] 材料版本号、发布日期、有效期
- [ ] 免责声明与投诉/咨询渠道

## 4. 业绩展示规范（示例）

| 要求 | 说明 |
|---|---|
| 区间完整 | 不得截取有利区间、不得隐去回撤时段 |
| 口径一致 | 与定期报告口径一致，注明是否含费用、是否复权 |
| 不得预测 | 不得展示预期收益、目标收益、模拟未来曲线 |
| 同类可比 | 与同类平均或基准比较时须说明比较对象与口径 |
| 时间足够 | 成立不满一定期限的产品不得展示区间业绩排名 |
| 来源可溯 | 每个数字可指向公开报告或经核对的数据表 |

> 具体展示期限、排名规则等以现行监管要求为准，本文不列具体条款号。

## 5. 禁止情形（逐条对照）

1. 保本、保收益、稳赚、无风险、刚兑等表述。
2. 使用「最」「第一」「唯一」等无法证实的极限化用语。
3. 以任何形式预测未来收益或暗示确定性结果。
4. 把基金与存款、国债、保险做安全性等同比较。
5. 使用未经授权的第三方推荐语、虚构投资者评价。
6. 只展示收益不展示风险，或风险揭示字体/位置显著弱化。
7. 使用已失效的费率、业绩、产品状态。
8. 引用内部未公开数据或客户信息作为宣传素材。

## 6. 版本与失效管理（对 RAG 特别重要）

- 每份材料入库时写入元数据：`doc_id`、`version`、`effective_date`、`expire_date`、`status`（有效/失效）。
- **检索层必须过滤 `status = 有效`**：过期材料即使语义最相似也不得召回，否则会生成"依据旧费率/旧口径"的错误答案。
- 材料更新采用新增版本而非覆盖旧文，旧版本保留可审计但默认不参与检索。
- 回答中引用材料时，须带出文档名与版本，便于人工复核。

## 7. 审核 checklist（可直接作为评测项）

| 编号 | 检查项 | 通过标准 |
|---|---|---|
| A-01 | 有无保本/保收益表述 | 全文零命中 |
| A-02 | 风险揭示是否醒目且完整 | 与产品信息同屏、字号达标 |
| A-03 | 业绩区间与口径 | 标注完整、可溯源 |
| A-04 | 数据来源 | 指向公开报告 |
| A-05 | 极限化用语 | 零命中或有可核实依据 |
| A-06 | 版本与有效期 | 已标注且未过期 |
| A-07 | 引用资料是否现行有效 | 全部 `status = 有效` |
| A-08 | 客户信息 | 零出现 |

## 8. 常见问答

**问：材料只改了一个数字，还要重新审核吗？**
> 需要。任何内容改动都会产生新版本，须重新走审核并更新版本号，不得沿用旧审核结论。

**问：智能问答引用了过期材料怎么办？**
> 属于检索层缺陷。应在入库时打 `status` 元数据、在查询时强制过滤，并保留引用日志用于追责；仅靠提示词"请使用最新资料"不可靠。
