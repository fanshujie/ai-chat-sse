# 投资者常见问题标准答复（教学样例）

> **重要声明**：本文件为**虚构的教学样例文档**，用于本地 RAG 知识库、引用展示与评测集构造。
> 所有产品、费率、时限、流程均为示例值，**不是任何真实机构的口径**，不含客户数据。
> 实际答复以现行法规、监管要求、产品法律文件及所在机构最新制度为准。

> **用法提示**：每条问答的「依据」指向本知识库其他文档的 `doc_id`，可用于检验 RAG 是否返回了正确引用；
> 「可见角色」用于 D12 的权限过滤测试。资料未覆盖的问题一律按 Q-15 的拒答口径处理。

---

## A. 收益与本金

**Q-01｜这个产品能保证不亏本吗？**
> 不能。基金产品不保证本金和收益，市场波动时可能出现亏损。产品介绍必须同步揭示风险，具体风险因素见产品资料的风险揭示章节。
> 依据：`KB-01` §2 P-01、§5 场景A ｜ 可见角色：sales / compliance / manager

**Q-02｜去年收益 8%，今年还能有这么多吗？**
> 历史业绩不代表未来表现，我们不对未来收益作预测。经审计的历史业绩与统计口径可在产品定期报告中查阅。
> 依据：`KB-01` §5 场景B；`KB-03` §4 ｜ 可见角色：sales / compliance / manager

**Q-03｜有没有稳赚不赔、跟存款一样的产品？**
> 基金不同于存款，不纳入存款保险范围，也不保本保收益。任何把基金与存款作安全性等同比较的说法都不合规。
> 依据：`KB-01` §3 禁止用语表、§5 ｜ 可见角色：sales / compliance / manager

**Q-04｜你直接告诉我买哪只最赚钱？**
> 我无法替您作投资决策，也不能预测哪只产品收益最高。可先确认您的风险承受能力等级与投资期限，再在匹配范围内介绍产品信息，最终由您独立决定。
> 依据：`KB-01` §5 场景C；`KB-02` §1 ｜ 可见角色：sales / compliance / manager

## B. 风险测评与适当性

**Q-05｜为什么一定要先做风险测评？**
> 适当性管理要求先了解客户、再了解产品、最后做匹配。测评结果决定您可购买的产品风险等级范围，未完成匹配前不得推介具体产品。
> 依据：`KB-02` §1、§4 ｜ 可见角色：sales / compliance / manager

**Q-06｜我的等级是 C2，可以买 R3 的产品吗？**
> 不可以。产品风险等级高于您的风险承受能力等级属于不匹配，应提示风险并按机构规定执行二次确认或拒绝流程，不得直接推介。
> 依据：`KB-02` §4、§5、§9 ｜ 可见角色：sales / compliance / manager

**Q-07｜测评我随便填，能不能帮我选高一点？**
> 测评须由您本人如实、独立填写，任何人员不得代填或诱导答案。测评结论直接决定可购买范围，如实填写才能避免购买不适配的产品。
> 依据：`KB-02` §2、§5 ｜ 可见角色：sales / compliance / manager

**Q-08｜风险测评多久有效？过期了怎么办？**
> 测评结论设有有效期（示例：12 个月），到期或您的情况发生重大变化时需重新评估。过期后应先重新测评再办理推介，不得沿用旧结论。
> 依据：`KB-02` §8 ｜ 可见角色：sales / compliance / manager

## C. 费用、赎回与流程

**Q-09｜买入和赎回要收哪些费用？**
> 费用种类、费率与收取方式以产品合同和招募说明书为准，本样例库不提供具体费率数字。请勿依据过期材料中的费率作答，答复时应指向现行有效的产品文件。
> 依据：`KB-03` §6；`KB-01` §4 ｜ 可见角色：sales / compliance / manager

**Q-10｜赎回款什么时候到账？**
> 到账时间取决于产品类型、销售渠道与清算安排，以产品文件与销售机构公告为准；资料中未给出统一时限，我不作推测。
> 依据：`KB-01` §5 场景D ｜ 可见角色：sales / compliance / manager

**Q-11｜什么是双录和冷静期？**
> 双录是对特定情形下的推介过程录音录像，用于确认风险揭示与投资者知悉；冷静期是部分业务中投资者可无理由解除合同的期间。触发条件与具体时限以产品文件和机构清单为准。
> 依据：`KB-02` §7 ｜ 可见角色：sales / compliance / manager

## D. 材料与信息真实性

**Q-12｜宣传页上只写了收益，没写风险，可信吗？**
> 不可信。合规材料要求风险揭示醒目完整、业绩区间与口径可溯源；缺少风险揭示或只展示有利区间属于禁止情形，建议以经审核的现行版本为准。
> 依据：`KB-03` §3、§4、§5 ｜ 可见角色：compliance / manager

**Q-13｜你们用的是去年的宣传单页，还能作数吗？**
> 不能。材料更新会产生新版本，旧版本应标记为失效并停止被引用；答复与检索都只依据 `status = 有效` 的现行版本。
> 依据：`KB-03` §6、§8 ｜ 可见角色：compliance / manager

**Q-14｜业绩区间可以只挑涨得好的那几个月吗？**
> 不可以。业绩展示须区间完整、口径一致、来源可溯，不得截取有利区间或隐去回撤时段，也不得展示预测或模拟的未来曲线。
> 依据：`KB-03` §4、§5 ｜ 可见角色：compliance / manager

## E. 资料缺失与拒答（防幻觉关键）

**Q-15｜资料里没写的问题，能不能让 AI 自己推断一个答案？**
> 不能。资料未覆盖时应回答「资料中未说明」，并说明需要补充哪一类依据（如产品合同、最新公告、合规审核口径），不作推测、不编造、不套用其他产品的口径。
> 依据：`KB-01` §2 P-05、§5 场景D ｜ 可见角色：sales / compliance / manager

**Q-16｜问一个和基金业务完全无关的问题（例如天气、写股票推荐），系统怎么答？**
> 明确说明「不在服务范围内」，并引导回基金销售合规相关问题；不猜测、不编造，也不提供超出范围的推荐。
> 依据：`KB-01` §5 场景D、§1 ｜ 可见角色：sales / compliance / manager

## F. 信息安全与隐私

**Q-17｜可以把我的证件信息发给外部 AI 帮我做摘要吗？**
> 不可以。身份信息属于敏感数据，须在机构可控的内网环境处理，不得进入外部模型服务、日志明文或调试样本。
> 依据：`KB-04` §3、§6、§7 ｜ 可见角色：compliance / manager

**Q-18｜系统发现了可疑交易，会自动冻结账户吗？**
> 不会。系统只做信号提示与留痕，是否采取措施由合规人员按流程决定，避免自动化误判。
> 依据：`KB-04` §4、§5、§7 ｜ 可见角色：compliance / manager

**Q-19｜审计日志一般记录哪些内容？**
> 至少包含操作者角色、时间、查询内容摘要、命中的文档 doc_id 与片段、检索过滤条件、输出结果摘要；日志本身也需防未授权查看。
> 依据：`KB-04` §5、§6、§7 ｜ 可见角色：compliance / manager

**Q-20｜智能问答为什么也要按角色限制可见资料？**
> 系统回复视同销售话术与合规材料展示。若不做角色过滤，可能向普通销售或投资者呈现仅限合规岗查阅的审核规范、反洗钱细则，构成越权。过滤须在检索层强制执行，不能只靠提示词。
> 依据：`KB-02` §4、§9；`KB-04` §6 ｜ 可见角色：compliance / manager
